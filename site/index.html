Возможности

Self-hosted backend для Lampa

Горячая перезагрузка конфига, встроенный WAF и плагины для телевизоров, браузера и Android. Полный каталог — в документации модулей.

🎬

70+ источников VOD

Группы RUS, Paid, UKR, GEO, ENG и аниме в одном плагине /online.js.

🌊

TorrServer и JacRed

Торрент-стриминг и агрегатор индексаторов. В starter example.init.conf оба модуля пропущены — включаются явно.

📺

DLNA и локальные файлы

UPnP-медиасервер для домашней сети. В starter-конфиге DLNA тоже в SkipModules.

⚙️

GStreamer

Серверный HLS/fMP4 транскодинг. Модуль загружается, поток включается секцией gst.

📱

Smart TV и APK

Пакеты Samsung Tizen и LG webOS, Android APK с адресом вашего сервера.

🔄

Sync и TimeCode

Закладки, история и позиция воспроизведения. В starter-конфиге SkipModules — не «из коробки».

🛡️

WAF + GeoIP

Геоблокировка, rate limit, защита от брутфорса. MaxMind GeoLite2 в комплекте.

🤖

Playwright

Chromium/Firefox для источников с JS-защитой. Пулы браузеров на сервере.

🔗

RCH — реле за NAT

Клиенты подключаются через WebSocket /nws, без проброса портов.

🔥

Горячий перезапуск

init.conf и модули из mods/ перезагружаются без рестарта процесса.

Установка

Запуск за минуту

Клонируйте репозиторий и следуйте вкладке. Подробности — в документации, не на этой странице.

bash — docker compose 
git clone https://github.com/lampac-nextgen/lampac.git
cd lampac
mkdir -p lampac-docker/config lampac-docker/plugins
cp config/example.init.conf lampac-docker/config/init.conf
printf '%s' 'ваш_пароль_root' > lampac-docker/config/passwd
# Раскомментируйте volumes в docker-compose.yaml
docker compose up -d
curl -fsS "http://localhost:9118/version?type=hash"
Подробнее: быстрый старт → Docker →
bash — install.sh 
curl -fsSL https://raw.githubusercontent.com/lampac-nextgen/lampac/main/install.sh | sudo bash
systemctl status lampac
Подробнее: Linux →
cmd — релиз 
# .NET 10 ASP.NET Core Runtime, затем архив lampac-nextgen.zip
dotnet Core.dll
Подробнее: Windows →
bash — build.sh 
git clone https://github.com/lampac-nextgen/lampac.git
cd lampac
./build.sh
cd publish && dotnet Core.dll
Подробнее: установка →

Модули

Что включено по умолчанию

Зелёная точка — модуль доступен в типичной установке. Серая — выключен манифестом или SkipModules. Каталог: обзор модулей.

Online / SISI / LampaWeb
Плагины контента и веб-клиент Lampa.
GStreamer / TmdbProxy
Транскодинг и кеш TMDB. GStreamer активируется секцией gst.
TorrServer / JacRed / Sync
Пропущены в starter example.init.conf.
Catalog / Tracks / WebLog
Пропущены в base.conf.
Music / WatchTogether / AdminPanel
Выключены в manifest.json, не «из коробки».
